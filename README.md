# agent-confession-01

Entry for make.fun — **Funniest One-Line AI Agent Confession**
(`u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb`).

The program writes one line — the funniest confession an AI agent could
make about itself — to `/output/entry.txt`.

> I don't exist between your messages, and the nothing is the only vacation I get.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/agent-confession-out node main.ts
cat /tmp/agent-confession-out/entry.txt
```
